SloCal Fulfillment preview

Read README.md in this folder for the desktop and mobile page-consolidation plan.

This folder contains the page HTML, bundled JavaScript, CSS, and local artwork.
The HTML file is not standalone because the site is a Next.js application.

To preview it locally, run this command from inside this folder:

  python3 -m http.server 8000

Then open http://127.0.0.1:8000/ in a browser.

This is a visual preview. The consultation form backend is not included in this folder.
